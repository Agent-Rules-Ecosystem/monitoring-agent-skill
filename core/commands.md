# ⚡ Comandos de Monitoreo ($monitoring)

- `$monitoring`: Bootstrap de habilidades de observabilidad.
- `$monitoring:audit`: Auditoría completa de logs, métricas y Sentry.
- `$monitoring:logs`: Generación de logger JSON agnóstico con contexto.
- `$monitoring:metrics`: Configuración de exportador de métricas Prometheus/OTel.
- `$monitoring:sentry`: Configuración e integración de Sentry / GlitchTip.
- `$monitoring:alerts`: Generación de reglas de alerta en Prometheus o Grafana.
