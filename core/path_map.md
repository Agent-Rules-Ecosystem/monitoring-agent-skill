# 🗺️ Mapa de Rutas de Observabilidad

- `lib/core/logging/` o `src/common/logger/`: Implementación del Logger estructurado.
- `lib/core/telemetry/` o `src/common/telemetry/`: Configuración de Tracing y OpenTelemetry.
- `sentry.properties` / `config/sentry.json`: Archivos de configuración de Sentry.
- `monitoring/prometheus/alerts.yml`: Reglas de alerta para Prometheus.
- `monitoring/grafana/dashboards/`: Modelos JSON de tableros de Grafana.
